# Indaly

App da nossa viagem — Índia, Nepal e Itália (30/out a 17/nov/2026).

É um site estático instalável (PWA) publicado pelo GitHub Pages. Roteiro, passagens, reservas e vistos ficam
**trancados** na pasta `cofre/` (criptografia [age](https://age-encryption.org)) e só abrem com a senha do grupo.

- Abrir: https://daniel-exo.github.io/indaly/
- iPhone: Safari › Compartilhar › Adicionar à Tela de Início
- Android: Chrome › menu › Instalar app

Manutenção: ver `ferramentas/LEIA-ME.md`.
